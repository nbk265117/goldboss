Dataset: 9 images generated by `scripts/generate-ocr-fixtures.ps1` — system fonts on plain backgrounds, no
game assets (clean, level suffix, light-on-dark UI-like panel, three names, 13 px text, blurred, 6 % noise,
no entity, 45 % downscaled). Entities: seed bosses.

| Metric | Value |
|---|---|
| Entity recall | **100 %** (10/10) |
| Entity precision | **90.9 %** (10/11) — the extra candidate is *Guerre (Tempête de l'Eliocalypse)* for the text "Guerre": two real bosses share the name, the outcome is **Ambiguous** and the user is asked, which is the intended behaviour |
| Mean character error rate (best attempt) | **0 %** |

These numbers describe synthetic text only. **No accuracy is claimed for real game screenshots**: building
an annotated set of user-provided screenshots is the next step.

## UI automation (`scripts/ui-smoke.ps1`)

Drives the running app through Windows UI Automation (own windows only, no keystrokes sent anywhere).
Run on the **self-contained release** without any .NET installed, clean data folder: **14/14 checks pass** —
main window, accent/case-insensitive search ("KRALAMOURE geant"), mechanic detail with ordered steps,
verification status and source, explicit "no documented mechanic", no-result message, overlay toggle and
back, overlay quick search, compact guidance with ordered steps.

Manually verified with window inspection: the overlay is shown top-right, is **not** the foreground window
after showing (focus not stolen). Display affinity is `0x0` (visible to Discord/OBS) and switches to `0x11` only while the app takes its own capture (first versions kept `0x11` permanently, which hid the overlay from Discord screen sharing — fixed after user report).

## Incidents seen while testing (reported, not hidden)

- Smart App Control blocked a freshly built **Release** test assembly once (0x800711C7, every test failed
  with `FileLoadException`); the Debug build of the same code passed 89/89. Not a code defect; see
  known-limitations.md. `test.ps1 -Configuration Debug` is a workaround on such machines.
- The search latency test failed once (median 261 ms) in a full-suite run immediately after a rebuild, while
  new binaries were being scanned; it passed 3/3 alone and 2/2 in full-suite reruns. Warm-up was increased.

## Not automated

DPI scaling across mixed-DPI monitors, behaviour over an actual Dofus window in exclusive fullscreen, and
click-through usability were not tested on multiple hardware setups; see known-limitations.md.
